MATHS · गणित
If 3x + 5 = 20, what is x?
यदि 3x + 5 = 20, तो x का मान क्या है?
🎯

Understand the steps / हल समझें

Subtract 5 from both sides: 3x = 15. Divide both sides by 3: x = 5.

दोनों तरफ से 5 घटाएँ: 3x = 15। फिर 3 से भाग दें: x = 5।

Tip: Try to solve first, then check the explanation.

Free launch plan / वेबसाइट शुरू करने की योजना

Use this checklist to take the site from a file to a public website.

1️⃣

Finish content / सामग्री

Choose 2–3 popular chapters first. Write accurate original notes, answer keys and practice questions. Check each topic against the current official CBSE syllabus and NCERT textbook.

2️⃣

Publish free / मुफ़्त प्रकाशित करें

Save this HTML file. Create a GitHub account, upload it to a repository as index.html, then enable GitHub Pages in the repository settings. The hosting provider's instructions may change, so follow its current guide.

3️⃣

Grow and monetize / कमाई

Share useful pages, improve titles, make navigation easy and gather feedback. After you have original content and real visitors, review current Google AdSense eligibility rules. Later consider original downloadable revision packs.

Important: This is a starter demo, not an official CBSE site. Verify the latest syllabus, do not copy copyrighted guidebooks, and never promise exam results. Ads and earnings are not enabled or guaranteed.
